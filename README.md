# 小学古诗·背学练 🏮

统编版小学 1—6 年级古诗在线背诵与考点练习网页，供学生复习记忆使用。

网址：https://lhjj111.github.io/shici/

## 功能
- **篇目浏览**：101 首古诗，按 10 大考点分类（爱国报国 / 忧国忧民 / 田园山水 / 思乡思亲 / 送别友情 / 豁达乐观 / 咏物言志·哲理 / 惜时劝学 / 节日风俗 / 童趣闲适），支持搜索
- **背诵模式**：逐句遮住记忆，一键朗读（浏览器 TTS），标记"我会背了"
- **闯关练习**：三种题型——补名句（选下句）、考考点（思想感情）、看字默写（打字填空，优先挖易错字）
- **错题本**：答错自动收录，可一键重做
- **学习进度**：背诵进度、答题正确率，保存在本机浏览器（localStorage）

## 技术说明
- 纯静态网页（HTML + 原生 JS），无任何依赖，可离线打开
- 数据文件 `poems.js` 由 `parse.mjs` 从复习手册 Markdown 解析生成：
  ```
  node parse.mjs   # 重新生成 poems.js
  ```

## 更新方法
修改后直接提交推送即可自动发布（Pages 部署）：

```bash
git add -A
git commit -m "更新"
git push
```

约 1 分钟后访问 https://lhjj111.github.io/shici/ 即可看到更新。

## 文件结构
- `index.html` — 网页本体（界面 + 全部逻辑）
- `poems.js` — 古诗数据（自动生成，勿手改）
- `parse.mjs` — 从 Markdown 手册解析数据的脚本
